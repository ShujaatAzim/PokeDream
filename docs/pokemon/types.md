# Typing Changes

PokéDream rebalances Pokémon typings to create a healthier type ecosystem while remaining faithful to each Pokémon's biology, behavior, appearance, and established lore.

The primary goals of these changes are to:

- Improve Pokémon viability.
- Reduce overused type combinations.
- Give Pokémon stronger individual identities.
- Incorporate successful typing concepts introduced in later generations where they naturally fit.

## Major Trends

### More Meaningful Types

Many Pokémon that naturally embody two distinct elemental or biological traits now receive a secondary type, particularly when later generations or official media reinforced that interpretation.

Conversely, many Pokémon were simplified to a single type when one of their original typings existed primarily as a design convention rather than a meaningful part of their identity. For example, simply having wings or resembling a bird no longer automatically implies the Flying type, nor does merely inhabiting the water automatically imply the Water type. Instead, typings were chosen to better represent each Pokémon's biology, behavior, and overall design.

### Fewer Default Dual Types

Several overused type combinations have been reduced, including:

- Normal / Flying
- Grass / Poison
- Rock / Ground
- X / Water just because it lives in or near the water.
- X / Flying just because it has wings or looks like a bird.

This allows individual Pokémon to develop stronger identities while creating a healthier overall type ecosystem.

### Evolutionary Progression

Some evolutionary families no longer share the same typing throughout every stage. In several cases, secondary types are introduced later in the evolution line to better represent each Pokémon's growth and development.
