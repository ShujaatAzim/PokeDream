# Move Changes

PokéDream reimagines many existing moves to improve type balance, increase move diversity, and make underused attacks more viable while remaining (mostly) faithful to each move's identity.

| Move | Changes | Reason |
|------|---------|--------|
| Bite | <ul><li>Type: Normal → Dark</li></ul> | Gives Dark a mid game move, and matches later generations. |
| Dragon Rage | <ul><li>Base Power: 40 → 90</li> <li>Category: Physical → Special</li> <li>Effect: No longer deals 40 static damage.</li></ul> | Turns it into a powerful, late-game Dragon special attack. Evokes the scariness implied in the show. |
| Pound | <ul><li>Type change: Normal → Fairy.</li></ul> | Matches later generations, and also serves as the basic Fairy move. |
| Rock Throw | <ul><li>Accuracy: 65% → 100%</li> <li>PP: 15 → 20</li></ul> | Makes an early Rock move reliable, and is also TM34 so will be available early. |
| Sand Attack | <ul><li>Type: Normal → Ground</li> <li>Base Power: 0 → 20</li> <li>PP: 40 → 20</li> <li>Effect: Damage AND 100% single accuracy drop.</li></ul> | Basically Mud-Slap from Gen II. Better thematic fit, adds an very early Ground attack, and introduces damage + 100% secondary effect moves. |
| Sonic Boom | <ul><li>Type: Normal → Steel</li> <li>Category: Physical → Special</li> <li>Base Power: 20 → 40</li> <li>Effect: No longer deals 20 static damage.</li></ul> | Turns an early, oft-forgotten and unused move into a basic Steel special attack. Also, Voltorb and Magemite, the signature users, are both part Steel now so it fits. |
| Thunder | <ul><li>Accuracy: 70% → 85%</li> <li>PP: 10 → 5</li> | Matches the other high-level elemental power moves (e.g., Fire Blast). |

# New Moves

PokéDream introduces moves from later generations to improve type coverage and support the three new types.

| Move | Type | Category | Power | Accuracy | PP | Effect | Reason |
|------|------|----------|-------|----------|----|--------|--------|
| Crunch | Dark | Physical | 80 | 100% | 10 | 20% chance to lower target's Defense. | Matches Gen II but swaps to the Defense-lowering chance as in generations post pysical/special split. |
